# Run the public showcase on either Mac

Use Python 3.12 or newer. Clone this repository into a local folder on each Mac, create a separate virtual environment, install `requirements.txt`, and run `streamlit run app.py`. The app opens at http://127.0.0.1:8501/ on that computer. Run `python test_showcase.py` to check the public showcase.

GitHub is the shared source backbone: pull before editing and push reviewed commits before moving between computers. Keep virtual environments, credentials and runtime files local to each machine. Avoid running a database or Python environment from a simultaneously synced cloud folder.

This repository provides the public scientific showcase. The full internal presentation, reviewed quantum evidence, platform captures and saved live-response replay are distributed separately through the fund-controlled private handover. Public installation does not establish platform authentication or a shared team AI service.
