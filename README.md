# Quantonation Labs

A public showcase of scientific AI and quantum research interfaces: animated arrays, an interactive Rabi reference, exact six-spin dynamics, and a proposal-derived orchestration view.

This edition contains local calculations and labelled architecture illustrations. It contains no measured hardware campaign, raw quantum counts, private research dialogue, fund document, credential or live model execution. Platform links use each service’s own access.

Run with Python 3.12: install requirements.txt, then start Streamlit with app.py.

The internal implementation belongs in a separate private fund-owned repository. Runtime state, secrets and private evidence stay outside this public source.

## Laptop and Mac Studio

See [Mac setup and source coordination](MAC_SETUP.md) to use this showcase on either computer. GitHub shares source; each Mac runs its own local app. The complete fund presentation and evidence release are maintained separately in the private handover.
